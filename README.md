## Novidades
- Gerenciamento completo de imagens pelo admin, com tamanho, proporção, formato e prévia.
- Foto principal, Sobre, TEA, logo e assinatura configuráveis.
- Foto individual em avaliações e resultados.
- Planos com publicar/ocultar/destaque e exibição automática na Home.
- PWA instalável pelo navegador, com manifesto, ícones e service worker.
- Base pronta para push notifications quando o projeto estiver online e integrado a um serviço de push.

## Observação
A versão local usa localStorage para testes. Notificação push real precisa de HTTPS e backend/serviço de push configurado.
